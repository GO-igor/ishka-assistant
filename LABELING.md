# Инструкция по разметке датасета

## Формат
Одна строка `data/*.jsonl` = один диалог: `{"messages": [...]}`. Порядок ролей:
`system` → `user` → (`assistant` с `tool_calls` → `tool`)* → `assistant` (текст).
Образец формата: `data/sample.jsonl` (данные выдуманы, в обучение не идёт). Схема инструментов: `tools.json`.
Настоящий датасет собирает `gen_dataset.py` из базы `db/` через `backend.py`: ответы инструментов в нём реальные.

- **system**: шаблон из `build_samples.py`, но *меняй* дату, время, день недели и группу.
- **tool_calls**: только инструменты из `tools.json`, только описанные аргументы.
- **tool**: JSON-ответ бэкенда — бери его из `backend.py`, а не пиши руками.
- **финальный ответ**: опирается *только* на данные из `tool`.

## Правила стиля
- На «ты», 1–5 строк, списки для пар и маршрутов, 0–2 эмодзи.
- Время — 08:30, дни — «пн/вт» или «завтра (чт)».
- Без канцелярита («Ваш запрос обработан» — нельзя).
- Нет данных → честно сказать и предложить, что можно сделать. Никаких выдуманных аудиторий и ФИО.
- Не хватает параметра (когда напомнить? какая аудитория?) → один короткий уточняющий вопрос.
- Удаление: номер — только из списка, который Ишка показала раньше; «удали все» — сначала вопрос, удаление после «да».

## Пропорции (ориентир на ~2300 диалогов)
| Категория | Доля |
|---|---|
| Расписание (сегодня/завтра/день недели/«какая следующая пара») | 12% |
| Аудитории, маршруты, «успеваю ли я» | 12% |
| Преподаватели | 5% |
| Д/З: записать / показать | 9% |
| Напоминания и заметки | 9% |
| Утренний брифинг (вход `[авто] утренний брифинг`) + настройка | 5% |
| Сессия: экзамены, план повторения | 7% |
| Дедлайны лаб и курсовых | 7% |
| «Объясни тему» (без инструментов, 3–8 строк, пример из жизни) | 7% |
| Многошаговые (расписание → маршрут, «запиши Д/З к следующей паре по …») | 7% |
| Уточняющие вопросы, ошибки инструментов, пустые результаты | 5% |
| Болтовня, вне темы, отказ выдумывать | 5% |
| Удаление и лимиты: список с номерами, «удали 2», «удали все» → «да», «уже 10 заметок» | 10% |

Д/З (к следующей паре, хранится неделю или до срока) и дедлайны (лабы/курсовые, любой срок) — разные
инструменты: «задали задачи на пятницу» → `add_homework`, «лабу сдать до конца месяца» → `add_deadline`.

## Разнообразие формулировок
Пиши как пишут студенты: «чё по парам», «где ауд 412», «кто ведет прогу»,
«матан/дискретка/физра», опечатки, без знаков препинания, голосовые расшифровки.
Одно намерение — минимум 10 разных формулировок.

## Как генерировать быстрее
1. Шаблоны фраз в `gen_dataset.py` (функция на каждую категорию) × реальные данные из базы.
2. Большой LLM перефразирует часть ответов (`data/paraphrases.json`), `paraphrase.py` проверяет, что факты не поменялись.
3. Человек выборочно проверяет диалоги (особенно аргументы и отсутствие выдумок).
4. `python validate_dataset.py data/train.jsonl` — должно быть «Ошибок: 0».
5. Eval-набор (`data/eval.jsonl`) не пересекается с train по формулировкам: последние 2 фразы каждого списка
   в `gen_dataset.py` идут только в eval. Новые категории в eval — поровну, по 5 примеров.
